# Project Scope

This project provides a reusable watershed intelligence pipeline for DEM-based hydrological modelling, morphometric analysis, structural drainage interpretation, flood hazard mapping, and sub-basin prioritization.

## In Scope

- Configurable data paths and processing parameters.
- DEM clipping, reprojection, hydrological conditioning, and terrain derivatives.
- D8 flow direction and flow accumulation.
- Stream extraction, vector conversion, and stream ordering.
- Watershed and sub-basin polygon outputs.
- Morphometric tables and interpretation fields.
- Optional lineament-drainage integration.
- Weighted overlay flood hazard index modelling.
- Sub-basin priority ranking.
- Static maps, charts, report assets, and Streamlit dashboard.

## Out of Scope

- Automatic download of heavy DEM or thematic datasets.
- Creation of a new Python environment.
- Hydraulic flood depth modelling.
- Guaranteed automated geological lineament extraction.
- Replacement for local expert validation.
